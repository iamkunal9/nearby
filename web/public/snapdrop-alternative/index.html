SnapDrop alternative: Nearby

Want the classic “open a tab on both devices and send a file” habit — without depending on SnapDrop’s current live site? Nearby is an independent open-source option for same-network peer-to-peer transfers in the browser.

Try Nearby View source

Quick answer

  • Nearby — browser P2P on the same Wi‑Fi, MIT-licensed, self-host on Cloudflare Workers + Pages.
  • Not affiliated with SnapDrop or LimeWire. Nearby is a separate project.
  • Files are not uploaded to a server; WebRTC carries bytes device-to-device.
  • If you need cross-network pairing codes, look at PairDrop; Nearby is same-network by design.

Nearby vs classic SnapDrop

Nearby Classic SnapDrop idea
Same Wi‑Fi auto-discovery Yes Yes
Transfer path WebRTC P2P (signaling only on server) WebRTC P2P (classic)
Accounts / installs None None
Cross-network / TURN No (by design) Typically same-network
Self-host Cloudflare Workers + Pages (Bun) Own Node / Docker instance
License / affiliation MIT · independent Separate project (live site later acquired by LimeWire)

Who Nearby is for

  • You want a SnapDrop alternative that stays auditable and self-hostable.
  • Both devices are on the same network (home, office, hotspot).
  • You prefer a small Cloudflare-native stack over running Node yourself.

Who should pick something else

  • PairDrop — if you need pairing codes / rooms across networks.
  • LocalSend — if you want native apps and are fine installing software.
  • AirDrop / Quick Share — if you stay inside one vendor ecosystem.
